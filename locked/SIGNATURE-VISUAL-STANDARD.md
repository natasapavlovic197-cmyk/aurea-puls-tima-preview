# AUREA Signature — visual standard

Owner direction, 2026-11-24. Applies to employee, manager, personal analytics and character experience during unified visual polish. Preserve exact locked masters and approved copy; implement in derived integration surfaces only. No deployment authorized by this document.

## Palette
- Primary Royal Burgundy #590F2B (owner-approved replacement of previous primary burgundy).
- Proposed supporting tokens: ivory #FAF6EF, antique gold #B99A68, espresso #51413F; retain existing compatible background and border tokens where appropriate.
- Ten stable domain hues remain distinct; harmonize and test contrast, never use hue alone to imply favorable/unfavorable results. Explicit text, direction and units required. No unmeasured scores.
- Gold is decorative/progress accent, not low-contrast body text. Check WCAG AA contrast for text and meaningful controls, visible keyboard focus, selected state and disabled state.

## Visual attention and typography
- Reading order: orienting title, concise context, information/evidence, one clear primary action. Adapt where a task requires a different order; preserve semantic DOM order.
- Use the existing Kringle italic serif treatment as visual reference (owner screenshots: Vaš sledeći korak, Provera zaposlenih). Inspect actual font stack and weights before applying; no arbitrary replacement font. Selective italic for narrative headings and reflective moments, not entire paragraphs, data, labels, navigation, questions, button text or system messages. Preserve approved wording. No invented slogans.
- Regular readable type for task content. Consistent type scale, contrast, spacing and line length; avoid competing headings. Respect text zoom and narrow mobile screens.
- Maintain consistent primary/secondary action styling, logical placement, progressive disclosure of methodology and optional settings. Never hide material limitations or privacy information behind inaccessible controls.
- Preserve original layout unless a targeted improvement is needed and verified; avoid repeated hero competing with current task. Keep role boundaries and real versus fictional data explicit.

## Motion and QA
- Subtle natural motion, no holographic effect, no animation blocking interaction. Honor reduced-motion preferences. Keep semantic content visible after animation. Verify Andjela against Marko separately.
- Check mobile 390px and desktop 1280px, actual iPhone preview before acceptance. Capture settled screenshots, test navigation, keyboard/focus, no horizontal overflow and readability. Compare both roles and ten-domain palette; distinguish mock QA from live staging. No main changes, live emails, TinyFish use or deployment without approval.

## Status
Royal Burgundy and selective existing Kringle italic approved as design direction. Supporting token choices are proposed implementation defaults. This file records rules only; it does not claim CSS implementation, browser verification or owner acceptance of final screens.
